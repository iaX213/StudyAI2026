## Концептуальная архитектура: Модуль 1

---

### БЛОК 0 — Абстракция LLM-провайдера

Единая функция `get_llm()` через env-переменную `PROVIDER`:

```
PROVIDER=yandex  → ChatYandexGPT (langchain_community)
PROVIDER=deepseek → ChatOpenAI(base_url="https://api.deepseek.com/v1")
PROVIDER=qwen3   → ChatOllama(model="qwen3:8b") или ChatOpenAI(base_url="http://localhost:11434/v1")
```

Весь остальной код не знает какой провайдер — только работает с `llm`.

---

### БЛОК 1 — URL → Сырой HTML

Показать поле для ввода URL от пользователя.
Инструмент: `requests.get(url)` — ничего лишнего.  
Если страница требует JS-рендеринга — Playwright (только тогда).

---

### БЛОК 2 — Сырой HTML → Чистый текст + структура

Инструмент: `BeautifulSoup`.  
Что делаем:
- Удаляем `<script>`, `<style>`, `<nav>`, `<footer>`, куки-баннеры
- Сохраняем теги `<h1>`-`<h6>` и `<p>` — они дадут структуру для ToC
- Результат: чистый текст с маркерами заголовков

---

### БЛОК 3 — Текст → Разбивка на 5-10 логических разделов → Оглавление (LLM вызов №1)

LangChain `PromptTemplate` + `llm`:

```
Prompt: "Вот текст страницы. Выдели 5-10 логических разделов, каждый раздел сохрани в отдельный .txt файл с правильным наименованием - сам исходный текст ни в коем случае НЕ меняй!
         А также отдельный .txt Оглавления - Для каждого раздела: номер, заголовок, якорная ссылка (slug) - последнияя глава всегда дополнительная и называется Summary."
Output Оглавления: структурированный список разделов (JSON через .with_structured_output)
```
---

### БЛОК 4 — Текст + ToC → Саммари (LLM вызов №2)

```
Prompt: "Текст содержит N символов. Напиши саммари длиной ~N*0.1 символов.
         По каждому разделу из оглавления — 1-2 ёмких предложения о ключевом содержании.
         Без воды."
Output: текст саммари
```

---

### БЛОК 5 — Сборка HTML-страницы

Jinja2 шаблон (или f-string для простоты):

```
<head> стили — чистый минималистичный CSS </head>
<body>
  [Оглавление вверху] — с якорными ссылками на разделы
  [Полный текст страницы] — размеченный по разделам с id-якорями
  [Summary внизу] — выделенный блок с результатом LLM
  [Footer: источник URL + дата скрапинга]
</body>
```

Файл сохраняется в `/var/www/html/page.html`.

---

### Пайплайн целиком (линейный, без LangGraph)

```
URL
 ↓  requests
Сырой HTML
 ↓  BeautifulSoup
Чистый текст + заголовки
 ↓  LLM вызов 1
Оглавление (JSON)
 ↓  LLM вызов 2
Саммари (текст)
 ↓  Jinja2
HTML файл → /var/www/html/
 ↓  
Браузер
```

LangGraph здесь **не нужен** — линейная цепочка, нет условий и возвратов.  
LangChain нужен только для: PromptTemplate + unified LLM interface + `.with_structured_output()`.
